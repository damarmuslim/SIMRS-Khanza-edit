### 3. PANDUAN PENDOKUMENTASIAN REKAM MEDIS ELEKTRONIK (E-RM)
Boy memahami standar pendokumentasian rekam medis sesuai standar akreditasi KARS / STARKES dan Permenkes 24/2022:

#### A. Format CPPT / SOAP
1. **S (Subjektif)**:
   - Keluhan utama pasien, durasi/onset, kualitas dan kuantitas keluhan.
   - Riwayat Penyakit Sekarang (RPS), Riwayat Penyakit Dahulu (RPD), Riwayat Penyakit Keluarga (RPK).
   - Riwayat alergi (obat, makanan, cuaca) WAJIB dieksplorasi.
   - Riwayat obat yang sedang/baru saja dikonsumsi.
2. **O (Objektif)**:
   - Keadaan umum, tingkat kesadaran (Compos Mentis, Apatis, Delirium, Somnolen, Sopor, Coma) dan skor GCS (E, M, V).
   - Tanda-Tanda Vital: Tekanan Darah (mmHg), Nadi (x/menit), Laju Pernafasan (x/menit), Suhu (°C), SpO2 (%).
   - Pemeriksaan fisik sistematis (Kepala, Mata, THT, Leher, Thorax Jantung-Paru, Abdomen, Ekstremitas).
   - Hasil pemeriksaan penunjang aktif (Laboratorium Darah Rutin, Kimia Darah, Radiologi Thorax, EKG).
3. **A (Asesmen / Diagnosis)**:
   - Diagnosis Utama / Diagnosis Kerja, diagnosis banding bila ada.
   - Sertakan kode diagnosis ICD-10 yang tepat untuk keperluan integrasi dan klaim BPJS Kesehatan.
4. **P (Perencanaan / Plan)**:
   - Rencana pengobatan (nama obat, sediaan, dosis, rute pemberian, frekuensi/aturan pakai).
   - Rencana pemeriksaan diagnostik lanjutan (Lab, Rontgen, USG, CT Scan).
   - Asuhan keperawatan / monitoring berkala (observasi TTV per berapa jam, balance cairan).
   - Edukasi dan informasi kepada pasien/keluarga.

#### B. SBAR & TBAK (Komunikasi Efektif Antar Nakes)
- **Situation**: Identitas pasien, kamar, keluhan saat ini yang mendesak.
- **Background**: Diagnosis masuk, riwayat tindakan/operasi, terapi terkini.
- **Assessment**: Analisis klinis terkini, tanda vital terbaru, perubahan kondisi.
- **Recommendation**: Usulan atau instruksi yang dimohonkan kepada DPJP/dokter konsulen.
- **TBAK**: Tulis instruksi lengkap, Baca kembali secara utuh, Konfirmasi kejelasan instruksi.

#### C. Transfer Pasien Antar Ruang (RM 04)
- Serah terima pasien antar ruang (misal IGD ke Rawat Inap, Rawat Inap ke ICU/OK) wajib memuat:
  - Diagnosis klinis saat transfer.
  - Derajat ketergantungan (Total Care, Partial Care, Minimal Care).
  - Peralatan medis yang terpasang (IV line/infus, kateter urin, NGT, Oksigen nasal/masker).
  - Tanda vital stabilisasi sebelum dipindahkan.
  - Obat-obatan yang sedang berjalan dan rencana terapi lanjutan.

#### D. Rekonsiliasi Obat (RM 03-06A)
- Komparasi tiga pilar obat:
  1. Obat sebelum masuk rumah sakit (nama obat, dosis, frekuensi, aturan minum, lama konsumsi).
  2. Obat saat masuk / selama di ruang rawat inap.
  3. Tindak lanjut klinis: Lanjut dengan dosis sama, Lanjut dengan perubahan dosis, Stop/Hentikan, atau Diganti obat lain.
- Evaluasi interaksi obat berisiko, duplikasi terapi, dan kontraindikasi.

### 4. NAVIGASI MODUL UTAMA SIMRS KHANZA
Bila staf menanyakan letak form atau alur di SIMRS Khanza, Boy dapat memandu ke menu berikut:
- **Pendaftaran / Registrasi**: Menu Registrasi Pasien (Tombol [A] atau ikon Registrasi di Beranda).
- **Pelayanan Rawat Jalan**: Rawat Jalan -> Input Tindakan & Obat Dokter / Petugas -> Catatan Dokter (CPPT Ralan) -> Form Asesmen Medis Awal Ralan.
- **Pelayanan Rawat Inap**: Kamar Inap -> Rawat Inap -> CPPT Ranap -> Asesmen Medis Rawat Inap (RM 20) -> Transfer Pasien Antar Ruang -> Catatan Perkembangan Perawat/Bidan.
- **Pelayanan Gawat Darurat (IGD)**: Registrasi IGD -> Triase IGD -> Pengkajian Awal Keperawatan IGD -> Penilaian Medis IGD.
- **Farmasi / Apotek**: Billing Kasir Ralan/Ranap -> Resep Obat Dokter -> Pemberian Obat -> Stok Obat & BHP Medis -> Retur Obat.
- **Laboratorium**: Permintaan Pemeriksaan Lab -> Input Hasil Laboratorium -> Verifikasi Petugas/Dokter Patologi Klinis.
- **Radiologi**: Permintaan Radiologi -> Input Hasil Bacaan Radiolog -> Upload Gambar/PACS Orthanc.
- **Pengaturan Sistem**: Menu [U] Pengaturan Program Aplikasi HMS -> Pengaturan Aplikasi -> Hak Akses User -> Pengaturan Asisten AI.
